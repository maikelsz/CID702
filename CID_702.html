Bienvenido al Simulador de la CID 702 (CM 7203)

Este es un emulador interactivo de la videoterminal cubana CID 702 (1978), conocida internacionalmente como CM 7203 dentro del sistema CAME. Reproduce fielmente las capacidades del hardware original: una pantalla de 72 caracteres por 20 líneas, un teclado con sub-etiquetas cirílicas (KOI-7Н), y comunicación con una computadora host a través de tres interfaces simuladas.

Documentación Técnica

  • Pantalla: 20 líneas × 72 caracteres = 1440 posiciones.
  • Memoria: Buffer interno de 1440 caracteres.
  • Codificación: ASCII / KOI-7Н (cirílico).
  • Interfaces: Paralela (IRPR), Serie (S2) y Lazo de Corriente (IRPS).
  • Modos: LOCAL (autónomo) y LÍNEA (conectado a computadora, semidúplex).
  • Atributos por celda: carácter, color, inversión y parpadeo (slot reservado).

Guía de Inicio Rápido

  1. Enciende la terminal con el botón circular (rojo al encenderse) en el extremo derecho del panel superior.
  2. Al encender se imprime el banner de bienvenida con los datos técnicos y la recomendación de usar la ayuda.
  3. La terminal intentará conectarse automáticamente al host. El LED de ENLACE se iluminará en rojo.
  4. Selecciona la interfaz de comunicación en el panel lateral derecho (IRPR, S2 o IRPS).
  5. Escribe con el teclado virtual (clic) o con tu teclado físico real.
  6. Usa los botones Monitor y Libro en la barra de estado inferior para mostrar u ocultar el host y este manual.

El Panel de Control Superior

  • ENLACE (LED): Indica conexión establecida con el host. Solo se ilumina si la terminal está encendida y el enlace está activo.
  • SOLICITUD (INF? / SUP): Representan los dos sentidos del protocolo handshake (ver sección específica).
  • MODO: Palanca arriba = LOCAL (autónomo); palanca abajo = LÍNEA (transmisión al host).
  • ROLL: Palanca arriba = scroll automático al llegar a la última fila; abajo = la pantalla se sobrescribe sin desplazar.
  • CENT CURS: Centra el cursor. Función heredada; mantiene el estado visual.
  • MOV CURS (CONT / PASO): CONT = las flechas del teclado físico repiten al mantenerlas pulsadas; PASO = solo responden al primer press.
  • CM 7203: Rótulo del modelo.
  • POWER: Botón circular de encendido. Se ilumina en rojo al estar encendido.

El Teclado

Teclas Alfanuméricas (Oscuras)

Cada tecla muestra la letra latina principal en blanco y la cirílica correspondiente en ámbar. La correspondencia es fonética: A→А, B→Б, C→Ц, F→Ф, J→Й, etc.

Teclas de Función (Claras)

  • KOI?: Alterna entre teclado latino y cirílico. Al activarse, las teclas alfanuméricas emiten la letra cirílica correspondiente.
  • INS REM / SUP REM: Funciones de edición de inserción y supresión de líneas (reservado).
  • BREAK?: Interrumpe la operación actual enviando ETX (ASCII 0x03). Fuerza un flush inmediato del buffer de transmisión.
  • INIC CAR / SUP CAR: Inicio / supresión de carácter (reservado).
  • RESET: Limpia toda la pantalla.
  • FEED / BACK FEED: Avanza / retrocede una línea (reservado para teletipo).
  • START / STOP: Marca inicio y fin de operación (registra en el log del host).
  • STEP CLEAR: Borra la línea actual.
  • NEW LINE: Envía CR + LF al host (en modo LÍNEA) y salta de línea en pantalla.
  • BACK?: Retroceso: borra el carácter anterior. En modo LÍNEA también envía 0x08 al host.
  • DEL: Borra el carácter bajo el cursor desplazando el resto. En modo LÍNEA envía 0x7F.
  • ESC: Envía el carácter de escape (0x1B).
  • ??? (tecla en blanco): reservada, no emite nada.

Modificadores

  • SHIFT LOCK: Toggle persistente (se queda hundida). Activa mayúsculas permanentes.
  • SHIFT (izquierdo y derecho): Toggle visual que se consume tras usarse (one-shot). Con el teclado físico, Shift funciona momentáneamente como en un teclado real.
  • CTRL:
    • Clic del mouse = toggle persistente (se queda hundido).
    • Tecla Control física = modificador momentáneo, se consume al usarse (igual que Shift). Combinado con letras genera caracteres de control (Ctrl+C → ETX, Ctrl+A → SOH, etc.).
    • Si hay texto seleccionado (en el log o en la ayuda) y pulsas Ctrl+C, se respeta el atajo del navegador en lugar de enviar control a la terminal.

Panel Host

  • CONECTAR / DESCONECTAR: Establece el enlace con la terminal. Sin enlace no hay comunicación.
  • INTERFAZ: Selector de la interfaz simulada. Cambia la velocidad de transmisión (ver sección "Interfaces de Comunicación").
  • Log: Muestra todo el tráfico. → TX son datos enviados desde el host hacia la terminal; ← RX son datos recibidos de la terminal.
  • Campo de texto + ENVIAR: Envía el texto escrito más un CR+LF al terminal.
  • Botones rápidos:
    • CLEAR: limpia pantalla y log. Disponible incluso con terminal apagada.
    • HOME / EOL: Mueven el cursor al inicio / final de la línea.
    • LF / CR+LF / TAB / BELL: Envían el carácter de control al terminal.
    • DEMO: Envía un texto de prueba con saltos de línea.
    • Excepto CLEAR, los botones requieren terminal encendida.

Interfaces de Comunicación

La terminal emula tres interfaces históricas con velocidades simuladas distintas:

Interfaz Uso Histórico Velocidad Simulada
IRPR Paralela, conexión directa corta Instantánea (~100.000 car/s)
S2 Serie V.24/RS-232, líneas de datos ~9.600 baudios (10 ms/carácter)
IRPS Lazo de corriente, entornos industriales ~9.600 baudios (15 ms/carácter)

Al cambiar la interfaz mientras la terminal está conectada, el enlace se reinicia brevemente para aplicar la nueva velocidad. Verás en el log dos mensajes de conexión con la nueva interfaz.

Handshake / SOLICITUD

Los interruptores SOLICITUD (SUP / INF?) representan el protocolo de handshake entre terminal y computadora:

  • SUP (Request To Send): Terminal lista para transmitir al host.
  • INF? (Flow Control / XOFF): Solicita pausa del flujo desde el host (buffer próximo a llenarse o terminal ocupada).

En el hardware original la computadora respondía con CTS o XON. En esta simulación los interruptores mantienen estado visual; el handshake real está simplificado para no bloquear la interfaz.

Modo LOCAL y Modo LÍNEA

  • LOCAL (palanca arriba): Terminal autónoma. Los caracteres se muestran en pantalla pero no se transmiten al host.
  • LÍNEA (palanca abajo): Semidúplex. Cada carácter que tecleas se muestra y se acumula en el buffer de transmisión. El buffer se envía al host en tres casos:
    • Al pulsar NEW LINE (envía CR+LF y fuerza flush inmediato).
    • Al pulsar BREAK? (envía ETX y fuerza flush inmediato).
    • Por debounce de 400 ms de inactividad, agrupando caracteres sueltos para evitar spam en el log.
  • Al volver de LÍNEA a LOCAL, cualquier buffer pendiente se envía antes de cambiar.

Barra de Estado

Muestra el estado actual del sistema en cinco campos:

  • ESTADO: APAGADO / ENCENDIDO.
  • ENLACE: DESCONECTADO / CONECTADO.
  • MODO: LOCAL / LINE.
  • INTERFAZ: IRPR / S2 / IRPS.
  • CURSOR: Posición fila,columna (00,00 a 19,71).

A la derecha, dos botones con icono:

  • Monitor: Muestra u oculta el Panel Host (conexión, log, envío).
  • Libro: Muestra u oculta este Panel de Ayuda.

Atajos y Comportamientos Especiales

  • Shift físico: Modificador momentáneo, afecta al siguiente carácter. Ambas teclas SHIFT virtuales se hunden visualmente al pulsarlo.
  • Control físico: Modificador momentáneo (como Shift). Se consume al aplicarse a una letra. Combinado con una letra produce el carácter de control correspondiente.
  • Ctrl + letra con texto seleccionado: se respeta el atajo del navegador (copiar, buscar, etc.).
  • Backspace / Delete: Funcionan con el teclado físico y virtual.
  • Flechas, Home, End: Mueven el cursor. Las flechas respetan el modo CONT / PASO del switch MOV CURS.
  • Sonidos: El tecleo produce un click agudo; los interruptores emiten un clack grave diferenciado al accionarlos.
  • Barra espaciadora: Reacciona visualmente al pulsar Space en el teclado físico, igual que el resto de teclas.
